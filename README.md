# personal-dashboards

개인용 단일 파일 웹 대시보드 모음. 각 대시보드는 **HTML 파일 하나**로 끝나고,
브라우저에서 더블클릭하면 바로 실행된다. 서버·빌드 도구·외부 라이브러리 없음.

|---|---|---|---|

Samsung Blue 계열 카테고리 색 구분.

### 오늘의 건강 대시보드
20대 생활습관 관리용. 식단·수면·운동 기록에 물 섭취 보조 트래커,
메모·체크리스트, 하단에 10점 만점 오늘의 점수(수면/운동/식단/물 각 2.5점).
디자인은 [DESIGN-airbnb.md](./DESIGN-airbnb.md) 기준 — 흰 캔버스 + ink + Rausch 단일 액센트,
카테고리 구분은 색 대신 인라인 SVG 일러스트.

## 기술 제약

- 순수 HTML / CSS / JS. 프레임워크·빌드 도구·CDN 없음
- 데이터는 `localStorage` (`morning-dashboard-v1`, `health-dashboard-v1`)
- 사용자 입력은 `textContent` 로만 삽입 (`innerHTML` 문자열 조립 금지)
- 라이트 / 다크 모드 병행

## 검증

기능 수정 후에는 검증 스크립트를 원본 HTML에 주입한 사본을 브라우저로 실행한다.
검증 스크립트는 산출물이 아니므로 원본 HTML에 포함하지 않는다.

| 대시보드 | 검증 스크립트 | 현재 |
|---|---|---|
| 관심종목 | `_test_inject.js` | 11 / 11 통과 |
| 헬스케어 | `_health_test_inject.js` | 22 / 22 통과 |

실행 방법은 각 태스크 문서 하단에 있다.
